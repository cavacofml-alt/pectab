Como ler o teu formulário de medidas

Formulários de medição em inglês usam termos diferentes dos campos aqui. Equivalências mais comuns:

No teu formulário (inglês)Campo aqui
Bag tag length / total tag lengthlen (mm)
Bag tag widthnão usado — a ferramenta só trabalha o eixo do comprimento
Passenger Stub lengthpax (mm)
Main tag part length / main tag lengthmain (mm)
Additional Stub(s) lengthadd (mm)
How many additional stubs / nº de talõesst
"Pax Stub" marcado como saindo primeirodir = PAX
"Additional Stubs" marcado como saindo primeirodir = ADD

Se o formulário listar mais do que um valor em "Additional Stub(s) length" (ex: "15 & 10") os talões não são todos do mesmo tamanho — a ferramenta só aceita um valor de add por busca. Corre "Procurar match" uma vez por cada valor e compara os resultados.

O campo tolerância len não existe no teu formulário — é só desta ferramenta: quantos mm de diferença entre o teu len medido e o len de um PECTAB ainda são aceites antes de o excluir da lista. 0 = exige igual.
